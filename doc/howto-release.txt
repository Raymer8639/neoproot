proot-scicat 发布指南
=======================

本文档概述了发布 proot-scicat 之前必须执行的检查。

发布前检查
----------

+ 安全性检查:
  * 代码中没有硬编码的敏感信息
  * 依赖库版本已更新至最新稳定版
  * 代码中没有已知的安全漏洞

+ 功能性检查:
  * 所有测试用例通过: `make test`
  * 代码风格符合项目规范
  * 文档已更新以反映新功能
  * 新增功能有适当的单元测试覆盖

+ 构建检查:
  * 在支持的平台上构建成功
  * 构建过程无警告
  * 交叉编译支持正常工作

发布流程
--------

1. 确保所有测试通过
2. 更新版本号和发布说明
3. 创建发布分支
4. 生成文档
5. 构建发布包
6. 验证构建产物
7. 创建 Git 标签
8. 上传到代码仓库

版本号管理
------------

proot-scicat 使用 SemVer 版本号方案:
- 主版本号: 不兼容的 API 变更
- 次版本号: 向后兼容的功能添加
- 修订号: 向后兼容的问题修复

发布标签格式应为: v{主}.{次}.{修订}
例如: v1.0.0
