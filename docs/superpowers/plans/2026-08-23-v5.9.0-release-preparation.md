# v5.9.0 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the unreleased v5.9.0 functionality release-ready by enforcing regression failures in CI, documenting the release, and completing the PR-to-tag workflow.

**Architecture:** The existing ARM64 matrix remains the build authority. Test-shell failure propagation is corrected at the script boundary, while each new deterministic regression is invoked as an explicit CI command so the failing condition is visible in Actions logs. Termux-only proc-dirfd coverage remains outside the generic runner and is verified by the established device workflow.

**Tech Stack:** GNU Make, POSIX shell, GitHub Actions, C regression probes, GitHub pull requests and releases.

- [ ] **Step 1: Demonstrate that the current scripts swallow a failed neoproot command**

Run the scripts with a command guaranteed to fail. Both commands currently

```markdown
## [v5.9.0] - 2026-08-23

**Compatibility, safety, and regression coverage release**

- link2symlink: add the opt-in `--link2symlink-dirent` mode, which reports
  verified `.l2s` pseudo-hard-links as regular directory entries while keeping
  the high-performance default unchanged.
- Performance: restore Termux `HAVE_PROCESS_VM` build detection so eligible
  builds use `process_vm_readv` and `process_vm_writev` instead of ptrace
  word-at-a-time memory access.
- bwrap/Codex sandbox: preserve covered bindings through pivot/oldroot and
  provide the virtual mountinfo view for inherited `/proc` directory fds.
- Safety: reject startup under a pre-existing ptrace tracer and direct users
  to run neoproot from the Termux host rather than nesting PRoot.
- CI: make basic and advanced smoke-script failures fatal and add process-vm,
  covered-oldroot, and traced-startup regressions to both ARM64 build modes.
```
